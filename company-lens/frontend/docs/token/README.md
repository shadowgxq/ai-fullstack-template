# 样式资产

当前界面使用现有 CSS Modules 和语义 token，实际值以 [src/shared/styles/tokens.css](../../src/shared/styles/tokens.css) 为准。主题和翻译接线见[使用指南](../frontend/guides/theming-and-i18n.md)。

这里保留上游的 [token 快照](tokens.css)、[视觉演示](demo.html)和[风格探索](style-exploration/README.md)，用于视觉来源参考；演示数据与页面内容不代表当前产品合同或新服务能力，文档不另行维护色值表。

`primary` 表示主操作与位置，证据状态和系统反馈采用各自语义 token；投资结论不能只由颜色表达。light/dark、键盘焦点、触控与文本状态要求见[交互规范](../frontend/standards/accessibility-and-ui-states.md)。
