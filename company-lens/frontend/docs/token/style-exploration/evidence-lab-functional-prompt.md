# AI Berkshire 公司研究工作台功能提示词

> 用途：作为页面设计、原型或前端实现的功能输入，仅规定产品功能、内容结构与交互规则，不绑定具体视觉风格。

请设计并实现一个“AI Berkshire 公司研究工作台”前端页面，只包含开始研究、Agent 研究过程、最终研究结果和研究记录四项核心功能。不得增加未描述的业务功能、虚构 API、数据模型、研究类型或 Agent。视觉样式可以调整，但不能改变功能含义、状态规则、数据边界和用户完成任务的路径。

## 1. 开始研究

页面内容：

- 新建研究项目
- 你现在想研究什么？
- 输入你的研究问题，也可以输入公司名或股票代码。

研究表单包含：

- “研究对象”可见标签
- 多行输入框
- 最多输入 200 个字符
- 实时字符计数
- 目标市场：港股、美股、A股
- 热门建议：腾讯、NVDA、美团、商业航天等
- “换一批”功能
- “开始研究”主按钮

交互规则：

- 点击热门建议后填充输入框，但允许继续编辑。
- `Ctrl+Enter` 或 `Command+Enter` 提交研究。
- 空内容提交时，在输入框附近显示错误并自动聚焦。
- 提交期间禁用重复提交并显示加载状态。
- 研究创建成功后进入 Agent 研究过程。
- 输入内容和目标市场在创建失败后保持不变，用户可以直接重试。

状态包括：

- 初始状态
- 输入状态
- 提交中
- 创建失败
- 创建成功

## 5. Agent 研究过程

页面展示：

- 当前研究对象
- 总体研究进度
- 运行中的 Agent 数量
- 已完成的 Agent 数量
- 已收集的证据来源数量
- 查看部分结果或完整结果入口

Agent 列表包含：

1. 行业研究
2. 瓶颈洞察
3. 质量筛选
4. 行业漏斗
5. 投资检查清单

每个 Agent 展示：

- Agent 名称
- 研究职责
- 当前状态
- 进度或来源数量
- 最新研究过程
- 报告是否可用

Agent 状态包括：

- 等待中
- 运行中
- 已完成
- 失败
- 已取消
- 状态未知

交互规则：

- 点击 Agent 行展开或收起研究过程。
- 展开状态使用 `aria-expanded` 和 `aria-controls`。
- 收起状态显示最新核心过程，展开状态显示完整研究记录。
- 已完成 Agent 提供“阅读报告”入口。
- 失败 Agent 提供“重试 Agent”。
- 重试期间禁用按钮并显示“重试中…”。
- 重试成功后更新 Agent 状态和反馈文案。
- 部分结果可用时允许查看结果，并明确标记内容尚不完整。
- 返回研究记录后再次进入项目时，恢复最新研究状态。

## 7. 最终研究结果

演示研究对象：

- 公司：腾讯控股
- 股票代码：0700.HK
- 市场：港股
- 信息评级：A
- 证据项：27
- 数据日期：2026.07.25
- 投资结论：观望
- AI 分析置信度：82%
- 公司投资确定性：68%

核心结论：

> 好生意已经确认，价格仍待验证。

辅助说明：

> 核心业务质量和现金流得到较强证据支持；当前投资判断主要受估值与新业务回报不确定性约束。

结果页包含：

- 公司与研究元数据
- 核心投资结论
- 投资状态
- 置信度
- 结论与证据账本
- 安全边际地图
- 后续观察信号
- 专业 Agent 输出

### 结论与证据账本

展示以下 6 条结论：

1. 核心业务仍具备强网络效应与定价能力
2. 自由现金流能够覆盖回购与核心投入
3. 视频号广告仍有两年以上结构性增长空间
4. 中性价值区间位于 HK$ 360–410
5. 大模型投入可以在三年内形成可量化回报
6. 当前价格未提供足够安全边际

每条结论包含：

- 编号
- 关键结论
- 证据状态
- 置信度
- 结论意义
- 证据来源
- 数据日期
- 使用限制或下一步验证

证据状态只有：

- 已验证事实
- 有据推算
- 信息缺失

交互规则：

- 支持“全部”“已验证事实”“有据推算”“信息缺失”筛选。
- 筛选后通过 `aria-live` 宣布当前结果数量。
- 点击结论行展开来源、解释和限制。
- 展开和收起不能引起不可控的页面跳动。
- 证据状态不能只依赖颜色，必须同时显示文字。
- 不得把“有据推算”或“信息缺失”包装成“已验证事实”。

### 安全边际地图

展示内容：

- 风险区间
- 中性区间
- 上行区间
- 当前演示价格位置
- 数值刻度
- 当前结论说明

图形信息必须同时提供文本说明，不能只依赖颜色或位置传达风险与结论。当前价格必须明确标记为演示数据，不得描述为实时行情。

### 后续观察信号

展示以下观察信号：

- 广告利润率
- 回购节奏
- 大模型投入回报

每个观察信号包含观察对象及需要满足或继续验证的条件。

### Agent 输出

- 展示参与本次研究的 Agent 名称和完成状态。
- 已生成报告的 Agent 提供“阅读报告”入口。
- 进入报告后可以返回结果页，并恢复原滚动位置。
- Agent 失败或报告缺失时明确保留缺口，不隐藏或伪造内容。

结果状态包括：

- 加载中
- 部分结果
- 完整结果
- 空结果
- 加载失败

加载失败时提供重试和返回研究记录操作。部分结果必须明确展示缺失报告、证据缺口和使用限制。

## 10. 研究记录

展示当前设备发起过的研究。

每条记录包含：

- 研究对象
- 对象类型
- 市场
- 创建日期
- 当前状态
- 查看入口

研究状态包括：

- 研究中
- 已完成
- 失败

交互规则：

- 支持按公司名称或研究主题搜索。
- 搜索结果即时过滤。
- 无匹配结果时显示空状态。
- 没有任何研究记录时提供“开始研究”入口。
- 进行中的项目进入 Agent 研究过程。
- 已完成的项目进入最终研究结果。
- 返回研究记录时保留搜索条件和页面位置。

所有公司、估值、行情、评分和结论均为视觉演示数据，不构成投资建议。不得接入或伪造实时行情，不得虚构后端返回结果，不得新增研究类型或未定义的 Agent。
