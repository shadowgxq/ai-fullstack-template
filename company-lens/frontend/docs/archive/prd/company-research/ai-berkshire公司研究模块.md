# 公司研究工具 MVP 产品文档

**产品名称：** 公司全方位研究
**英文名称：** Company Intelligence
**文档版本：** V1.0
**产品形态：** PC Web，兼容移动端 H5
**默认市场：** 美股
**支持市场：** 美股、港股、A股、日本股市、韩国股市
**核心研究引擎：**

- `/investment-research`
- `/investment-team`
- `/management-deep-dive`

## 一、产品定义

传统 Web 公司研究应用

用户只需要输入一个研究对象并点击“开始研究”，系统自动识别并补充对应的公司、股票代码、上市市场、所属行业、核心人物和业务关系。

系统通过三种研究模式，从商业模式、财务、行业竞争、管理层、风险和估值等角度进行全方位分析，最终输出多角度投资结论、研究共识、核心分歧以及可持续跟踪指标。

用户输入可以是：

- 公司名称
- 股票代码
- 创始人或管理层姓名
- 产品名称
- 品牌名称
- 子公司名称
- 业务板块名称

核心流程：

```
输入研究对象
↓
点击开始研究
↓
自动识别公司和市场
↓
自动生成研究计划
↓
自动调用研究能力
↓
展示研究进度
↓
输出结构化公司研究报告
```

---

# 二、核心产品原则

1. 用户只需要输入一个研究对象。
2. 开始研究不需要注册或登录。
3. 不要求用户选择市场、研究模式或关注方向。
4. 系统自动判断应该如何研究。
5. 报告采用传统 Web 页面模块结构展示。
6. 登录仅用于保存和管理历史分析记录。
7. 未登录用户同样可以完成完整研究并查看完整报告。
8. 报告必须提供明确结论，而不是只输出信息摘要。
9. 数据不足时明确说明，不生成虚假精确结论。

# 六、研究对象识别

## 6.1 功能目标

将用户输入的任意研究对象匹配到可研究的上市公司。

---

## 6.2 输入

```
用户原始输入
```

例如：

```
黄仁勋
```

---

## 6.3 系统处理

系统依次判断：

1. 输入对象属于公司、股票代码、人物、产品、品牌、子公司还是业务板块。
2. 对象对应哪家上市公司。
3. 对应公司的股票代码。
4. 对应公司的主要上市市场。
5. 所属行业。
6. 关键管理层。
7. 输入对象与公司的关系。
8. 识别结果是否唯一。
9. 识别置信度是否足够创建研究任务。

---

## 6.4 明确结果

例如输入：

```
黄仁勋
```

系统识别：

```
研究对象：黄仁勋
对象类型：管理层
对应公司：NVIDIA Corporation
股票代码：NVDA
上市市场：NASDAQ
所属行业：半导体 / AI算力
关键身份：创始人、总裁兼CEO
识别置信度：高
```

识别结果明确时：

1. 不要求用户确认。
2. 直接创建研究任务。
3. 跳转研究进度页。
4. 在进度页展示识别结果。

---

## 6.5 多个候选结果

当输入存在多个合理结果时，系统展示候选对象弹窗。

例如输入：

```
马斯克
```

展示：

```
请选择本次研究对象：

Tesla
NASDAQ：TSLA
Elon Musk担任CEO

SpaceX
未上市公司，当前版本暂不支持

xAI
未上市公司，当前版本暂不支持
```

业务规则：

- 最多展示5个候选结果。
- 上市公司候选项可以选择。
- 未上市公司显示“当前版本暂不支持”。
- 用户选择后立即创建研究任务。
- 不再进入其他设置步骤。

---

## 6.6 无法识别

系统输出：

> 暂时无法确认该对象对应的上市公司，请尝试输入完整公司名称、股票代码或管理层姓名。

页面操作：

- 修改输入
- 返回首页

---

## 6.7 不支持的对象

以下内容不进入公司研究：

- 宏观经济
- 行业主题
- 指数
- ETF
- 数字货币
- 商品
- 未上市公司
- 无法对应上市公司的普通概念

例如：

```
美国经济
AI行业
标普500
比特币
黄金
```

提示：

> 当前工具用于研究具体上市公司、管理层、产品或业务。

# 七、系统自动制定研究计划

用户不参与研究模式和研究重点选择。

系统根据对象类型自动制定研究计划。

---

## 7.1 输入为公司名称或股票代码

例如：

```
英伟达
NVDA
美团
3690
```

系统默认研究：

- 商业模式
- 核心产品
- 收入结构
- 护城河
- 财务质量
- 行业趋势
- 竞争格局
- 管理层
- 风险
- 估值

自动调用：

```
/investment-research
+
/investment-team
```

如果公司明显属于创始人驱动型公司，自动增加：

```
/management-deep-dive
```

---

## 7.2 输入为创始人或管理层

例如：

```
黄仁勋
王兴
雷军
马化腾
```

系统提高以下内容的研究权重：

- 历史公开承诺
- 承诺兑现情况
- 战略判断
- 历史关键决策
- 资本配置
- 并购和回购
- 困难时期表现
- 管理层持股
- 股东利益一致性
- 企业文化
- 接班人风险
- 关键人物依赖

同时保留完整公司研究：

- 商业模式
- 财务
- 行业
- 风险
- 估值

自动调用：

```
/management-deep-dive
+
/investment-research
+
/investment-team
```

研究主线：

> 从管理层切入，最终判断对应公司的整体投资价值。

---

## 7.3 输入为产品、品牌或业务

例如：

```
微信
美团外卖
AWS
FSD
YouTube
```

系统提高以下内容的权重：

- 产品解决什么需求
- 用户为什么使用或付费
- 收入模式
- 收入贡献
- 利润贡献
- 市场份额
- 竞争对手
- 业务护城河
- 增长空间
- 对所属公司估值的影响

同时补充母公司整体分析：

- 公司财务质量
- 管理层
- 行业风险
- 公司估值

自动调用：

```
/investment-research
+
/investment-team
```

必要时补充：

```
/management-deep-dive
```

研究主线：

> 从具体产品或业务切入，最终回到所属公司的投资价值。

---

## 7.4 输入为子公司

### 子公司已经上市

以该上市子公司作为主要研究主体。

### 子公司未上市

以母公司作为投资主体，重点分析：

- 子公司的业务价值
- 对母公司的收入贡献
- 对母公司的利润贡献
- 潜在隐藏资产价值
- 对母公司估值的影响

# 八、开始研究

## 8.1 用户操作

用户输入研究对象并点击：

> 开始研究

不论用户是否登录，都可以创建研究任务。

---

## 8.2 系统处理

```
校验输入
↓
识别研究对象
↓
处理歧义
↓
匹配公司与市场
↓
制定研究计划
↓
创建研究任务
↓
跳转研究进度页
```

---

## 8.3 未登录任务

未登录用户创建任务时，系统生成：

- 匿名用户标识
- 浏览器会话标识
- 研究任务ID
- 报告访问地址

研究完成后，用户可以在当前浏览器和当前报告地址查看结果。

未登录任务不自动进入账户历史分析。

---

## 8.4 登录用户任务

登录用户创建任务时：

- 任务自动关联当前账户。
- 任务自动进入“历史分析”。
- 用户可以跨设备搜索、查看和删除记录。

# 十、研究任务状态

| 状态值 | 前端文案 |
| --- | --- |
| `pending` | 等待开始 |
| `resolving` | 正在识别研究对象 |
| `collecting` | 正在收集资料 |
| `analyzing` | 正在分析 |
| `synthesizing` | 正在整理结论 |
| `completed` | 已完成 |
| `partial` | 部分完成 |
| `failed` | 研究失败 |

---

## 10.1 部分完成

如果部分研究能力失败，但已有足够信息形成报告：

- 任务状态为“部分完成”。
- 仍然输出报告。
- 在报告顶部提示未完成模块。
- 对相关结论降低置信度。

示例：

> 管理层深度研究未完整完成，本报告中的管理层结论置信度较低。

---

## 10.2 全部失败

展示：

> 本次研究未能完成。

失败原因使用用户可以理解的分类：

- 无法确认研究对象
- 可用公开资料不足
- 关键财务数据不足
- 研究服务暂时不可用
- 报告整理失败

用户操作：

- 重新研究
- 返回首页

# 十二、报告输出结构

## 12.1 公司基础信息

展示：

```
原始研究对象
对象类型
公司名称
股票代码
上市市场
所属行业
关键管理层
输入对象与公司的关系
报告生成时间
财务数据周期
市场价格更新时间
```

---

## 12.2 综合结论

固定输出：

```
综合结论：买入 / 观望 / 回避
结论置信度：高 / 中 / 低
公司质量：优秀 / 良好 / 一般 / 较差
当前估值：低估 / 合理 / 偏贵 / 无法判断
长期前景：积极 / 中性 / 消极
最大机会：一句话
最大风险：一句话
```

最终投资结论只能是：

- 买入
- 观望
- 回避

不能使用以下模糊表达替代最终结论：

- 值得关注
- 谨慎乐观
- 长期看好
- 可以研究
- 保持关注

---

## 12.3 对输入对象的直接判断

系统根据输入对象类型自动生成直接回答。

### 输入公司或股票代码

回答：

> 这是不是一家好公司，目前是否值得投资？

### 输入管理层

回答：

> 该管理层是否值得长期信任，以及其能力和风险如何影响公司价值？

### 输入产品或业务

回答：

> 该业务是否具有竞争力，以及其对所属公司的收入、利润和估值有多大影响？

示例：

```
你输入的是：黄仁勋

直接结论：
黄仁勋在战略判断、技术路线和组织执行方面表现突出，是英伟达竞争优势的重要组成部分；但公司对核心人物的依赖也构成长期治理风险。
```

---

## 12.4 商业模式

输出：

- 公司本质上是一门什么生意
- 核心客户是谁
- 客户为什么付费
- 公司如何获得收入
- 哪项业务是真正的利润来源
- 收入是否持续
- 是否具备经营杠杆
- 输入对象对商业模式的重要性

统一结构：

```
一句话结论
核心事实
支持证据
反对证据
结论置信度
```

---

## 12.5 护城河

输出：

- 主要竞争优势
- 品牌优势
- 技术壁垒
- 网络效应
- 规模效应
- 转换成本
- 数据或生态优势
- 竞争对手能否复制
- 护城河正在变宽还是变窄

# 二十三、MVP验收标准

## 23.1 开始研究

- 未登录用户可以直接开始研究。
- 用户只需要输入研究对象。
- 明确对象直接创建任务。
- 歧义对象可要求用户选择对应公司。

## 23.2 研究进度

- 使用传统任务进度页面。
- 刷新后任务状态不丢失。
- 任务完成后可以进入完整报告。
- 部分研究能力失败时仍可生成部分报告。

## 23.3 研究报告

- 使用传统 Web 长报告布局。
- 包含公司基础信息。
- 包含综合结论。
- 包含对输入对象的直接判断。
- 包含商业、护城河、财务、行业、管理层、风险和估值。
- 包含不同研究视角。
- 包含共识、分歧、牛方和熊方。
- 包含观察指标和数据来源。

## 23.4 登录与历史分析

- 登录不是开始研究的前置条件。
- 登录用户的新任务自动进入历史分析。
- 游客可以将当前报告保存到账户。
- 历史分析支持搜索。
- 历史分析支持查看报告。
- 历史分析支持删除记录。
- 用户只能查看和管理自己的历史记录。
