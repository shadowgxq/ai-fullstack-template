# ADR-0006：不可变报告和绑定hash的发布门禁

> 日期：2026-09-16｜状态：proposed（沿用业务v1.1准出并补取消竞态）  
> 实施/验证证据：尚无。

## 背景

一份审计后的报告若继续覆写正文、引用或数字，审计结论就不再对应读者看到的内容；通用artifact下载也可能绕过审计。

## 决定

Candidate、Audit、Delivery分别不可变，Audit绑定准确report_hash与policy_hash；发布事务检查取消/权限/当前输入，登记唯一正式指针。只有明确可展示的证据/计算和合法交付可供浏览器读取。

## 后果

存储与引用管理增加，修订产生新版本；partial只允许不完整但可靠的内容，已知错误不能放行。取消先接受则禁止随后发布，发布先完成则不回写为取消。

## 未采用的替代方案

覆写同一report.md；先发布后异步补审计；按同scope开放全部artifact；通过修改标题为partial掩盖错误。

## 复议触发条件

正式报告编辑/分享/公开发布若进入需求，需定义新版本与访问策略，不削弱现有hash和审计绑定。
