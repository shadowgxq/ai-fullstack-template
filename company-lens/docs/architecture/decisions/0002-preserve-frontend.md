# ADR-0002：保留前端实现，替换研究接入合同

> 日期：2026-09-16｜状态：accepted（仅表示用户已明确此决定；未实施验收）  
> 前端代码已复制；新接口适配和运行验证尚未进行。

## 背景

已有前端代码已迁入 `frontend/`，使用 CSS Modules / Radix UI。现有视觉与交互可复用，旧接口尚待迁移至新的 Run 合同；来源见[迁入记录](../../references/frontend-import.md)。

## 决定

保留现有CSS Modules、Radix封装、token、导航与已确认交互；研究数据改接统一Run API与公开DTO。需要的新增状态在既有设计内扩展。不得为了更换接口而新建整套页面壳或组件库。

## 后果

允许存在一个过渡DTO适配层；适配不得重算金融值、伪造成功或隐藏缺口。迁移要做受影响状态回归；只有实际无消费者的旧分支才移除。

## 未采用的替代方案

整体迁入Tailwind/shadcn；并行保留两套业务API与store；重新生成整个frontend。它们扩大本次变更范围且不能提高数据真实性。

## 复议触发条件

独立评估新的品牌/交互重构需求，或既有组件确实无法满足已批准的可访问性需求时再决策。与新Run合同接入无关的重构不自动纳入。
