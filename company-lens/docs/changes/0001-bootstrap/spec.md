# D0：服务骨架与前端契约通路

> change_id：0001-bootstrap｜状态：proposed / planned｜运行验证：not_run

## 目标与范围

在既有前端基础上初始化单一 Python 包 `ai_service`，建立真实依赖锁、最小 API、离线 schema 导出和前端连接/错误状态。沿用[系统技术架构](../../architecture/ai-architecture.md)与[工程规范](../../engineering/ai-development-standard.md)。

保留前端现有样式、组件、交互与锁文件，不重新创建 Vite 工程。D0 不实现真实取证、完整研究图、预算台账、估值、团队模式或公开部署；数据库、Worker 与恢复能力由系统架构第5.1、10.4节的 V1 可靠运行服务切片承接。D0 仅是工程准备，不能单独满足 V1 或 SYS-003 的验收；后续若合并规划，由新任务明确承接此任务，不双写完成状态。

## 最小接口

计划建立 `GET /health/live` 返回进程存活状态；它不表示数据库、供应商或研究能力就绪。公共 DTO/schema 导出不得连接数据库或模型；真实事件模型出现后再导出事件 schema。
