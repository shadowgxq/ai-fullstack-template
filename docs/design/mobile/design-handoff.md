## 页面与状态行为

- 首页：组件入口进入组件 Tab，外观与账户进入我的。未配置服务时显示中性说明并禁用检查；请求中防重复触发，成功、失败和离线分别反馈；检查不修改业务数据。
- 目录：基础控件与交互组合分类；中文名或英文组件名搜索与分类取交集。切换分类保留搜索词，清除搜索恢复全部；无结果引用 `C61RN`，不当作网络失败。返回保留目录条件及位置。
- 输入体验：正常、错误、禁用共用一个体验区；聚焦与错误引用 Field 的对应表达。空白名称校验显示就近错误，有效输入只反馈本地校验成功。切回正常保留输入并清除预览错误。
- 图片：选择期间防重复触发，成功替换本地预览；取消或失败保留旧图，失败显示错误。`MbfkW` 表达预览与重新选择，不自动上传或发布。
- 我的：登录进入登录页；账户加载用内容级骨架，失败保留会话并允许重试。`K1y29c` 表达已登录区域，显示真实用户名。退出失败保留会话，成功清理凭据与查询缓存；本地清理失败仍须可见反馈。
- 外观：跟随系统、浅色、深色互斥，立即应用界面与原生宿主；持久化失败显示错误，不伪报保存。系统是偏好，实际主题仍为 Light / Dark。
- 登录：用户名不 trim，1–50 个 Unicode 字符；密码非空、UTF-8 不超过 72 字节且无孤立代理字符，来源为 `features/auth/validation.ts`。Label 常驻，密码掩码；错误保留输入。提交中禁用并防重复，服务缺失禁用登录，失败不提前跳转。保存凭据成功后清密码及缓存并返回，无上一页时进入我的。

## 通用交互边界

- Textarea 保留常驻标签与字数提示；Switch 以位置及文本表达开关。Tabs 选项与面板一一对应，切换保留输入；disabled 不响应，focus 使用边界，不能只靠颜色。
- Select 的分组标题不可选，禁用项保留原因；点选应用并收起，关闭或返回保留原值。Calendar 先更新待选日期，确认才应用，返回不提交；禁用日期不可选。六月日历是固定示例，不代表真实当前日期。
- Dialog 说明对象、后果和恢复边界；取消、返回及遮罩不执行移除。确认只作用于当前本地示例。ActionSheet 的移除项先进入确认，取消不执行动作；复制成功后才反馈成功。
- Disclosure 通过点按展开与收起，不依赖 hover 或自动消失。浮层在真实设备中的居中、底部、安全区和滚动遵守移动 UI，不由组件展示板替代场景适配。
- 查询模式由调用方提供。查询中不可提交，失败保留输入并可重试；Hybrid 无候选且非查询中允许使用当前文字，remote_only 不提供该入口，直接表达模式不查询候选。
- 分享预览由调用方提供；复制、图片生成、相册保存分别反馈。取消不报错；生成失败保留预览，权限被拒提供设置指引，不宣称已送达或已保存。

## 实现与检查范围

小程序公开 API 以源码为准。Cell/Search、扩展选择控件和组合示例不因存在设计节点就视为已实现；没有修改业务代码或运行时 Token。

| 检查 | 当前范围 |
|---|---|
| 结构与引用 | 10 个根画板；82 个变量；组件引用、别名、布局与根画板重叠检查 |
| 视觉 | 主页面保持原取景；基础组件、交互组合、补充状态和新的底栏实例核对 Light / Dark |
| 安全区示意清理 | 当前编辑器已移除五页固定占位及主组件，回读无残留引用；五页 Light、三个 Tab 页 Dark 和宿主说明实际截图检查，页面保持 375 × 812 |
| 持久化 | 此前版本已保存回读；本轮安全区调整的保存与独立回读尚未执行 |
| 未执行 | 浏览器、小程序运行、真机键盘/滚动/安全区、分享与产品验收 |

组件展示板用于样式与状态定位，页面用于实际布局定位；二者不重复铺同结构的完整页面。
