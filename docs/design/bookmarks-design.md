# 个人资源收藏夹设计交付

## 需求与范围

来源：[个人资源收藏夹](../product/bookmarks-prd.md)（REQ-BOOKMARKS-001）；确认记录见 [当前进度](../../manager/progress.md)。当前范围已按新版 Skill 归并重复表达，完成保存回读与渲染核验，可供正式技术方案消费；不代表产品已实现。

目标为 `frontend/` React/Vite Web，覆盖电脑及手机浏览器。范围包含收藏浏览、搜索分页、新增编辑、删除确认、分组管理与当前页批量移动；非目标沿用 PRD §5。设计写入范围为业务消费稿、预览与本记录，不修改正式 Token、公共库或业务代码。

主路径：登录后进入收藏夹 → 保存资料 → 分组和关键词查找 → 查看备注、打开链接 → 单条维护或批量整理。行为来源为 PRD §3.1–3.5、§4，验收来源为 §6。

## 复用规则与恢复路径

- 加载列表复用 Skeleton 与 UI 状态规则，保持筛选和布局位置；刷新失败保留旧内容并提示未更新。空态按首次、空分组、无搜索结果替换内容区，保留导航和搜索。
- 收藏新增/编辑共用四字段表单，分组创建/重命名共用单字段表单；两个不同字段集合不合并。校验或明确保存失败保留输入，取消不改变已保存数据。提交使用 Button loading；结果未知显示查看最新结果入口，不直接提示重试创建。
- 批量明确失败保留有效选择；资源或目标不可用时按 PRD 原子失败并提示重新检查。翻页、筛选清空选择；成功后更新数量与归属，选择清空。分组删除失败不提前转移本地条目。
- 打开备注使用只读内容浮层，无备注显示“暂无备注”；编辑仍从行菜单进入。原网页由独立动作在新标签页打开。
- 新增 / 编辑打开时聚焦首个字段，校验失败聚焦首个错误；关闭回到触发点。菜单和 Select 沿已有键盘协议，选中必须有勾选语义，不能只依赖底色。UI 不替代账号权限；会话失效沿用认证宿主，不显示他人数据。
