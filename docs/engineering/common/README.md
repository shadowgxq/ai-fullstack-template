# 公共工程细则

公共协作入口见 [根 AGENTS.md](../../../AGENTS.md)。本文保留公共工程的实施细节，按任务读取对应章节，不是所有任务的额外必读项。服务职责与数据流见 [全栈架构](../../architecture/README.md)。

## 总分关系与读取范围

| 任务 | 公共规则 | 专项补充 |
|---|---|---|
| 新增或修改代码 | [代码质量](code-quality.md)：变量、注释、复用、正确性与复核 | 受影响端的编码入口 |
| Python 实现 | [Python 公共写法](python.md) | backend 的分层/事务，AI 的 Node/恢复 |
| 数据、配置与运行 | 本页对应章节 | 实际服务的存储与生命周期 |
| 选择验证范围 | 本页验证范围 | 受影响端 README 与测试规范 |

同一任务已读取的规则不重复加载；只修改文档时不追加代码必读链。前端特有的组件/状态、后端特有的 ORM/事务、AI 特有的 Checkpoint/副作用不提成跨端强制实现。规范的“总分”不新增公共运行时包或技术栈。

## 数据与依赖

- 同机 PostgreSQL 使用不同数据库与角色；测试不得使用生产连接串。
- 数据库变更必须有版本化迁移；应用库与 LangGraph Checkpointer 表的初始化分别管理，只在部署任务中显式执行，不在请求中建表。
- 可选缓存失败允许回源；认证、限流和 token 撤销依赖故障必须拒绝操作，不能假报成功。

## 配置与运行环境

- 环境变量在服务配置边界校验；`VITE_*` 会进入浏览器，只能配置可公开的信息。
- 根 Compose 仅用于本地，绑定 loopback；生产环境另需逐资源授权、配额、TLS、备份与观测。
- 日志不记录 token、密码、完整请求或供应商原始响应。
- 真实模型/工具调用在获得授权后，还需显式配置凭证和预算；初始化默认零外部调用。

## 验证范围

以下根命令在仓库根目录执行；各端命令与参数见对应 README，不在入口文件复制。仓库级文档、Manager、repair 与架构检查归根 `Makefile` / `scripts/`；各端 `check` 只负责本端代码，不依赖其他服务的工具环境。

| 变更范围 | 必要验证 |
|---|---|
| 仅文档变更 | `make docs`；不因此运行前端/后端业务单测或启动服务 |
| 单端代码 | 按涉及端 README/规范执行静态检查和相邻测试 |
| 共享契约 | 追加直接消费者回归；生成与校验方式见 [跨端契约](../../contracts/README.md) |
| 初始化、工具链或跨端实现 | `make check`；相关服务启动后运行 `make smoke` |

检查命令不隐式修改代码；格式修复和迁移使用独立命令。命令定义以 [根 Makefile](../../../Makefile)、[前端 README](../../../frontend/README.md)、[后端 README](../../../backend/README.md) 和 [AI README](../../../ai-service/README.md) 为准。
