# 公共工程约束

## 所有权与依赖

浏览器不持有 AI 服务凭证。后端负责用户、授权和业务资源，AI 服务负责运行执行。跨服务只通过版本化 HTTP/事件契约，不互相导入源码、不访问对方数据库。同机 PostgreSQL 使用不同库与角色。

通用层不包含公司、证券、报告、记账等业务实体。出现第二个真实调用者后再抽公共包，不提前创建万能 Agent 或重复 DTO。

## 配置与安全

环境变量经服务配置边界校验；`VITE_*` 会进入浏览器，禁止密钥。根 Compose 仅用于本地，绑定 loopback；生产另需逐资源授权、配额、TLS、备份、观测。日志不记录 token、密码、完整请求或供应商原始响应。

外部内容与模型输出是不可信数据。真实模型/工具调用需要显式配置、预算与授权，初始化默认零外部调用。

## 验证与变更

代码改动运行相邻测试；契约改动追加消费者回归。初始化/工具链/跨端变更运行 `make check`，启动后运行 `make smoke`；仅文档变更运行 `make docs`。检查不隐式修改代码；格式修复和迁移有单独命令。

数据库变更必须有版本化迁移；应用库与 LangGraph saver setup 分别管理，只在部署任务执行，不在请求中建表。测试不得使用生产连接串。当前后端 Redis 故障降级沿用模板，生产前必须复核认证、限流、token 撤销是否应 fail-closed。

根安全规则优先，端专项仅细化。需求与技术方案冲突时记录 ADR 或阻塞，不静默覆盖事实源。
