# 工具入口与上下文

[交付流程](delivery.md) 定义人和 AI 共用的工作规则；它不是自动调度服务。

根 `AGENTS.md` 为主入口，`CLAUDE.md` 仅转引；端 AGENTS 仅补充本端导航。OpenSpec 与 repair skills 唯一维护于根 `.agents/skills/`。使用不自动发现该目录的工具时，按需读取相应 SKILL.md，不新增正文副本。

模型名称、账号权限、沙箱配置及并发策略属于操作者环境，不写入模板默认值。仓库不默认开启无审批循环。需要并行时按交付流程提供每个子任务的读写范围与契约，共享文件由单一负责人合并。

从仓库根调用验证命令；端命令显式带目录。repair 仅由用户显式启用，不能为普通架构变更额外生成修复队列。

使用方项目归档已合并 change 时：先将生效要求同步至 `openspec/specs/`，再移动 change 到日期归档目录并修复相对链接，最后更新计划路径与阶段，禁止同时保留活动副本。PR 的合并事实以 GitHub 为准；模板自身的维护记录按 [文档维护规则](../../README.md#文档维护规则) 处理。
