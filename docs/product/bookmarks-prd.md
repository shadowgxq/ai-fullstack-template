# 个人资源收藏夹产品需求

需求编号：REQ-BOOKMARKS-001

## 1. 背景与目标

本功能面向需要在工作、学习和调研中收集网页资料的个人用户。用户发现一篇有价值的文章、一个工具网站或一份参考资料时，希望先保存下来；后续需要使用时，能够根据主题或记得的关键词重新找到。

例如，用户在调研支付方案时保存了多篇文章，当时还没有想好如何分类。几天后写方案，需要找到其中关于订阅的资料；调研结束后，希望整理分类，同时保留以后仍可能用到的链接。

资源收藏夹应帮助用户完成三件事：

- **及时保存**：只填写必要信息即可收藏，分类和备注可以稍后补充。
- **方便找回**：通过分组和关键词找到资料，直接打开使用。
- **轻松整理**：集中调整多条收藏的分类，清理分组时不会误删资料。

## 2. 核心使用场景

| 场景 | 用户希望完成的事情 | 期望结果 |
| --- | --- | --- |
| 发现资料，暂时没空整理 | 保存网页链接，并留下一句收藏原因 | 资料被保存；未选择分组时进入“未分组” |
| 再次使用，只记得部分信息 | 在全部收藏或某个分组中搜索关键词 | 找到匹配的收藏，查看备注并打开原网页 |
| 收藏积累，需要集中整理 | 新建分组，将多条相关资料移入其中 | 一次操作完成整理，能够看到各分组的最新数量 |
| 原有分类不再适用 | 重命名或删除分组 | 分类得到整理，已有收藏仍然保留 |

## 3. 功能需求与业务规则

### 3.1 保存和维护收藏

登录用户可以新增、查看、编辑和删除自己的收藏。每条收藏包含以下信息：

| 信息 | 填写要求 |
| --- | --- |
| 标题 | 必填，去除首尾空格后为 1–80 个字符，便于用户识别资料 |
| 链接 | 必填，支持完整的 HTTP 或 HTTPS 网页地址，最多 2,048 个字符 |
| 分组 | 可选，每条收藏只属于一个分组；未选择时归入“未分组” |
| 备注 | 可选，最多 500 个字符，用于记录收藏原因或使用提示 |

- 允许保存相同链接，用户可以使用不同标题、分组或备注区分用途。
- 新增和编辑完成后，用户能看到保存结果；离开后重新进入或再次登录，已保存内容仍然存在。
- 编辑时展示已有内容，用户可修改上述信息；取消编辑不改变原收藏。
- 不要求用户在收藏时验证网页是否能够访问。链接后来失效时，收藏仍保留，用户可以自行修改或删除。
- 打开收藏时，在新的浏览器标签页访问原网页，保留当前收藏夹的浏览位置。
- 删除单条收藏前，明确展示删除对象及“删除后无法恢复”的提示；用户确认后才删除。取消操作时内容保持不变。
- 删除收藏不会删除它所属的分组。

### 3.2 浏览和查找收藏

用户能够查看收藏标题、链接、所属分组和最近更新时间，并查看备注。

- 默认查看“全部”收藏，按最近更新时间从新到旧排列；新增、编辑内容和移动分组均视为更新。更新时间相同的收藏保持稳定顺序。
- 每页显示 10 条，能够看到当前条件下的收藏总数并翻页浏览。
- 用户可以按标题或链接中的关键词搜索，英文字母不区分大小写，忽略关键词首尾空格。
- 分组和关键词同时生效。例如，在“支付调研”分组中搜索“订阅”，只展示该分组内标题或链接包含“订阅”的收藏。
- 清空关键词后，恢复当前分组的全部收藏；选择“全部”后，搜索范围扩大到所有个人收藏。
- 分组旁的数量始终表示该分组的收藏总数，不随搜索改变；列表中的总数表示当前分组与关键词共同匹配的数量。
- 切换分组或改变搜索条件后，从第一页展示结果。
- 删除或移动导致当前页不再有效时，自动显示最后一个有效页面；仍有收藏时，不让用户停留在没有内容的页。

### 3.3 管理分组

用户可以根据自己的用途建立一级分组，例如“支付调研”“开发工具”“学习资料”。

- “全部”和“未分组”为固定入口，不能重命名或删除，也不能创建同名的自定义分组。
- 自定义分组名称去除首尾空格后为 1–30 个字符。同一用户不能创建重名分组，英文字母不区分大小写。
- 可以创建没有收藏的空分组；本期不支持分组嵌套。
- 重命名分组后，相关位置显示新名称，组内收藏保持原有归属和排列顺序。
- 删除分组前，告知用户其中有多少条收藏，并明确说明：**只删除分组，其中的收藏全部转入“未分组”。**
- 删除分组成功后，收藏总数不变；若用户正在查看该分组，则进入“未分组”查看结果。转入“未分组”的收藏更新最近更新时间；更新时间相同的收藏保持稳定顺序。
- 删除分组未成功时，分组及其中的收藏保持原状，不出现资料丢失或只转移一部分的情况。

### 3.4 批量整理收藏

用户可以选择当前页的多条收藏，一次移动到指定分组或“未分组”。

- “全选”只选择当前页的收藏，并清楚展示已选择的数量。
- 翻页、切换分组或改变搜索条件后清空选择，避免误操作此前看见的内容。
- 未选择收藏时不能发起批量移动；取消移动不改变收藏。
- 移动完成后，所选收藏归入目标分组，相关列表和数量随之更新，并清空选择。
- 已经位于目标分组的收藏保留原归属和最近更新时间，不产生重复收藏；只有实际改变分组的收藏更新最近更新时间。
- 一次移动要么全部完成，要么全部保持原状。若某条收藏或目标分组已经不可用，告知用户重新检查，不只移动其中一部分。
- 明确移动失败时，保留仍可操作的选择，便于用户重试。

### 3.5 个人范围与隐私

- 收藏夹需要登录后使用，每个账号拥有自己的收藏和分组。
- 用户只能查看和管理自己的内容，其他用户不能查看、修改、移动或删除这些内容。
- 本期收藏均为个人私有，不提供公开访问和分享协作。

## 4. 使用体验与异常情况

收藏夹应提供清晰的功能入口，方便用户在保存、查找和整理之间切换。电脑和手机浏览器均能完成主要操作；显示风格、语言和深浅模式跟随产品现有设置。

| 情况 | 用户应获得的反馈 |
| --- | --- |
| 第一次进入，还没有收藏 | 说明收藏夹的用途，提供添加第一条收藏的入口 |
| 当前分组为空 | 明确该分组暂无收藏，允许添加收藏或切换分组 |
| 搜索没有结果 | 告知当前条件没有匹配项，允许修改关键词或清除筛选 |
| 内容正在加载 | 显示正在加载，避免误导用户认为收藏已清空 |
| 内容加载失败 | 明确提示未能加载，提供重新尝试的入口 |
| 输入内容不符合要求 | 在相关输入位置解释原因，保留已填写内容 |
| 保存或整理明确失败 | 明确告知未完成，保留输入或仍有效的选择，允许重试 |
| 因网络中断暂时无法确认结果 | 告知结果尚未确认，提供查看最新结果的方式，避免误导用户重复操作 |

处理操作期间应有清楚的反馈，连续点击保存不应产生多条相同操作的结果。主要操作在手机上便于触达，在电脑上可通过键盘完成，文字、选中状态和错误提示能够清楚辨认。

## 5. 本期范围

本期交付个人网页链接的收藏、查找和分组整理能力。收藏由用户填写标题、链接和备注，不自动提取网页信息。

本期不包含文件上传、网页内容存档、自动摘要、标签体系、嵌套分组、拖拽排序、导入导出、分享协作和回收站。

## 6. 产品验收标准

以下从用户实际操作及可观察结果判断需求是否满足。

| 验收场景 | 满足要求的表现 |
| --- | --- |
| 保存一篇调研资料 | 填写标题和链接即可保存；不选分组时进入“未分组”；再次进入仍能找到 |
| 补充和修改资料信息 | 已有内容可查看和修改；保存后显示新内容；取消编辑保留原内容 |
| 找回需要的资料 | 关键词与分组筛选共同生效；分组总数与当前搜索结果数量含义清楚 |
| 整理分组 | 能新建和重命名分组；空名称、重名和系统名称受到明确提示，已有内容不受影响 |
| 清理过时分类 | 删除分组前告知后果；确认后组内收藏全部进入“未分组”，收藏总数不变 |
| 批量调整分类 | 只移动当前选择的收藏；数量与归属正确；失败时没有部分移动或收藏丢失 |
| 连续浏览和整理 | 翻页或改变筛选后选择被清空；移走某页最后一条收藏后，能继续看到剩余内容 |
| 删除不再需要的收藏 | 删除前说明不可恢复；取消时保留，确认后删除，所属分组仍存在 |
| 使用不同账号 | 各账号只看到并管理自己的收藏和分组，不出现他人的私有内容 |
| 遇到空内容或操作异常 | 能理解当前状态并知道下一步怎么做；输入不会因错误无故丢失 |
| 在不同使用环境中操作 | 电脑、手机及现有深浅显示模式下，都能清楚地完成保存、查找和整理 |
