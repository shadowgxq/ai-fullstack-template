# 产品需求

本目录用于使用模板创建项目后的真实产品需求。模板不预装业务 PRD，也不将模板初始化、清理或验证记录当作产品需求。

新增需求应明确稳定 REQ-ID、用户场景、范围、非目标和验收条件；实现状态与执行证据由关联 OpenSpec change 维护，不复制到 PRD。规划读取正文中的所有行为、失败与数据保证，保留源位置与限定；验收属于可独立交付的 change，不能承诺尚未引入的未来页面。

正式变更先在 [架构目录](../architecture/README.md) 复用或形成对应的技术总/专项方案并获得真实内容批准，再按 [交付流程](../engineering/workflow/delivery.md) 关联 [Manager](../../manager/plan.yaml)、契约与消费者。未排期范围明确留在路线图；批准后变化需分析影响并重新确认，不为生成覆盖台账修改 PRD 正文。模板维护记录的归属见 [文档维护规则](../README.md#文档维护规则)。
