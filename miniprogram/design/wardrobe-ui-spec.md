# 智能衣柜小程序 UI 规范

适用于 [wardrobe.pen](wardrobe.pen) 在 `miniprogram/` 中的实现，工程基线为 [Taro + React + TypeScript](../../docs/engineering/miniprogram/architecture/technology-options.md)。业务行为以 [PRD V1.2](../../docs/product/01-prd-draft.md) 为准，页面、状态及接受范围见 [设计交付](wardrobe-ui-ux.md)。

本页维护业务布局与通用移动规范的适配，通用规则引用 [移动 UI](ui-spec.md)，Token 来源引用 [移动 Token](tokens.md)。模板的 375px 代表宽度与原生示例导航不替代衣柜的 390px 业务稿和已确定的导航职责；业务稿没有另行对应的 Web/PC 实现。

## 布局与宿主

智能衣柜以微信小程序为目标，主设计尺寸为 390 × 820 逻辑 px，补查 360、375、430px。单列流式布局，左右留边 16px，不按屏幕宽度缩小字号或触控区域；较宽窗口共用字段与顺序，不另做 PC 页面。设计逻辑 px 不直接等同于运行时 rpx。

导航使用 56px 设计基准，标题 20px，返回及个人入口的画布视觉为 44px，运行时命中区按移动基线至少 48px。右侧保留微信系统胶囊空间，主页面个人入口放左侧，子页放返回。胶囊与系统状态栏均为宿主示意，实际由微信承载；自定义导航必须按真实胶囊矩形与状态栏适配，不能再叠一套系统导航。底部主导航保持“衣柜、穿搭、记录”三个入口；统计归记录，个人为二级页面。底部导航内容基准 60px，图标 24px、文字 12px、间距 4px；安全区另取设备环境。

顶栏、底部动作及导航与中间滚动内容分区，最后一项必须可滚动至完整可见并操作。状态栏 44px、底部安全区 24px 仅用于画布取景，不是运行时常量；不重绘系统状态栏和 Home Indicator。安全区与胶囊适配依据真实宿主信息，静态稿不证明已适配。

## 内容与操作

添加衣物默认仅展示照片、名称、分类和主要颜色，其他信息收在“更多属性”。照片区约 176px，明确区分拍照与相册；分类使用 Bottom Sheet，颜色使用快捷色块与更多颜色弹层，季节/场合/标签使用多选 Chip。收起不清空值；选中态配合勾选，颜色不能作为唯一提示。底部主按钮高 52px，输入控件高 48px、圆角 12px，为业务覆盖，不改变公共控件默认值。输入键盘出现时隐藏固定操作区，确保焦点字段可见，收键盘后恢复。具体必填与保存规则引用 PRD FR-001。

天气随内容滚动，长期偏好归个人页，一次性场景归穿搭页。图片圆角 16px；天气、推荐理由和历史以自然分区表达，不用多层边框卡片。穿搭页主操作仍为 50px。普通自定义操作的运行时触控区至少 48px；场景按钮视觉宽 88px、高 40px，筛选视觉高 32px，外层点击区至少 48px；窄屏颜色等紧凑控件可换行或局部滚动，命中区不重叠。业务颜色沿用 Signal Teal 的主题语义，不把参考图 HEX 值另建为平行色板。

个人页采用账户资料、穿搭设置及账户操作分组，不设整页“保存设置”；日期时区选择后保存并反馈，失败保留原有效值。头像昵称选填，微信登录不等同于自动取得头像昵称。微信登录、媒体选择、定位及原生资料填写的实际能力在小程序端实现；Web React 控件只提供设计样式参考；实现使用 miniprogram/ 的 Taro 组件及平台适配。

## 实现边界

优先复用小程序端 PageShell、Button、Field、Notice、StatePanel 等真实组件，具体能力见 [组件清单](../../docs/engineering/miniprogram/components/component-inventory.md)。当前 PageShell 适配原生导航与 TabBar，不能仅靠套用该壳实现稿中的自定义导航、固定操作区；业务增加这些区域时需明确安全区和滚动归属，避免重复 inset。复杂分类/颜色/标签弹层、多选 Chip 及可选资料填写属于待实现的业务组合。

共享品牌与状态色从 Web `global.css` 生成到小程序色板；尺寸、语义和组件别名以 `miniprogram/src/shared/styles/tokens.scss` 为运行时来源，业务确需的覆盖在对应角色或控件内定义，不修改模板所有页面的默认尺寸。Pen 的库实例和变量表达视觉依据，不直接导入 Web UI、Radix、Tailwind 或 React Router。

真实键盘、媒体权限、定位、登录和网络保存的检查归 [小程序运行验收](../../docs/engineering/miniprogram/guides/runtime-and-verification.md)；画布尺寸与静态预览不证明这些行为已实现。
