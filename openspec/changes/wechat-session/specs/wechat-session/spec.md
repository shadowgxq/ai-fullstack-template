# 微信账户与客户端会话

## Purpose

使用户以微信身份进入稳定归属的私人账户，并在资料尚未填写、认证失败、退出或切换账户时保持真实且隔离的状态；为后续衣柜资源提供可复用的会话边界，同时继续支持已有密码账户。

## ADDED Requirements

### Requirement: 微信身份稳定关联账户

系统 SHALL 仅由服务端交换临时 code 确定微信身份，相同应用下的相同身份重复或并发登录 MUST 对应同一 User。客户端不得指定 openid 或资源归属。交换失败 MUST 返回受控失败且不得建立成功会话，敏感凭据与 session_key 不得进入日志或公开响应。

#### Scenario: 首次及重复登录
- **WHEN** 同一应用下的微信身份首次、重复或并发成功登录
- **THEN** 返回同一账户的有效会话和本人标识，首次账户与身份创建保持原子性

#### Scenario: 无效或失败交换
- **WHEN** code 无效、交换超时、响应不合法或微信配置缺失
- **THEN** 返回受控错误，不创建孤立账户、不泄露提供方原文，并允许获取新 code 重试

### Requirement: 旧密码账户与默认资料

系统 SHALL 保持已有密码账户可登录，微信新账户不得凭空获得密码。认证用户 SHALL 只能读取本人 profile；未填昵称、头像和城市保持缺失，UI 显示默认头像与“衣柜用户”。接口和设置 MUST 不提供个人时区字段。

#### Scenario: 密码兼容与默认资料
- **WHEN** 旧密码账户登录，或无头像昵称的微信账户读取 profile
- **THEN** 密码认证保持有效，默认资料可读取且不阻塞后续业务，微信无密码账户不能通过密码校验

#### Scenario: 本人资料隔离
- **WHEN** 未认证或其他账户尝试读取非本人的资料
- **THEN** 未认证请求被拒绝，profile 查询仅返回认证身份的资料，不接受客户端 owner 作为授权依据

### Requirement: 登录持久化与页面状态

小程序 SHALL 仅提供微信登录主流程，凭据持久化成功后才进入已登录态。登录中 MUST 防止重复操作，取消、失败或持久化失败 MUST 可见且可重试，不展示受保护数据。

#### Scenario: 本地保存失败
- **WHEN** 微信交换成功但 token 持久化失败
- **THEN** 客户端仍未登录，清理可能残留的凭据且不进入私人页面

#### Scenario: 取消及重试
- **WHEN** 平台登录取消或接口失败后用户再次点击微信登录
- **THEN** 保留可操作页面并重新获取 code，不复用已经消费的 code

### Requirement: 会话代次与退出隔离

客户端 SHALL 按账户及会话代次隔离个人查询、草稿与在途请求。退出、切号或匹配会话的 401 MUST 使旧查询及回包失效；旧 401 不得清除新会话。退出 SHALL 尝试远端撤销，远端失败仍清理本地并准确提示；本地 token 删除失败时 MUST 由独立退出标记防止重新恢复旧凭据。

#### Scenario: 迟到响应与切号
- **WHEN** 旧会话请求在退出或新账户登录后才成功或返回 401
- **THEN** 旧数据不进入当前缓存或页面，新会话不被旧错误失效

#### Scenario: 撤销或存储失败
- **WHEN** 服务端撤销失败或本地 token 无法删除
- **THEN** 不宣称远端撤销成功；当前私人数据立即隐藏，持久退出标记阻止下次启动恢复旧 token
