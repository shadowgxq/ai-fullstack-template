# 微信账户会话

## Why

小程序目前只能使用模板用户名密码登录，无法把微信身份稳定关联到私人衣柜账户。依据 [PRD §3.1](../../../docs/product/01-prd-draft.md#31-登录与个人设置)，先建立可独立验证的微信登录、默认资料和会话隔离，为 M1 的衣柜资源提供认证边界。

## What Changes

- 新增微信临时 code 交换、身份归一与默认资料查询，保持旧密码账户可用。
- 登录页面消费微信能力；凭据持久化成功后进入登录态，失败或取消可重试。
- 统一账户与会话代次隔离、退出标记、缓存清理和迟到响应丢弃。

## Capabilities

### New Capabilities

- `wechat-session`: 微信身份登录、默认资料、客户端会话及退出隔离。

### Modified Capabilities

无。当前生效规格为空。

## Impact

影响 `backend/` 的认证、用户模型、Alembic 迁移和相邻测试，以及 `miniprogram/` 登录与请求/缓存生命周期；同步提供方 OpenAPI 和小程序生成类型。对应 AC-010、AC-022、AC-023 的默认资料及 AC-027 的无个人时区约束。

不在此项实现衣物、资料编辑、城市或完整业务导航；各资源 owner 验证由真实消费者完成。真实 AppID、合法域名与微信宿主体验保留接入待验，不以替身证明外部接入完成。
