# 个人资料与设置

## Why

账户、衣柜和实际穿着已完成代码检查，用户需要在个人页查看自己的真实内容，并管理可选头像昵称及退出。[PRD §3.1](../../../docs/product/01-prd-draft.md#31-登录与个人设置)与已确认个人页目标要求将内容展示和独立设置分开，不以填写资料作为登录门槛。

## What Changes

- 接通个人页“衣物 / 穿着记录”内容 Tab，复用真实衣物与历史查询、展示和添加入口；数据样例不进入产品。
- 支持可选昵称、本人头像的编辑与持久化，沿用私有媒体上传/鉴权下载，失败保留输入并处理并发冲突。
- 接通独立设置页、资料入口及真实退出确认，复用已验证的会话撤销/本地清理与旧回包隔离。

## Capabilities

### New Capabilities

- `personal-profile`: 本人个人内容页、可选资料编辑和独立设置/退出路径。

### Modified Capabilities

无。保留既有账户登录和数据归属；偏好与城市功能入口随其对应 Change 接通。

## Impact

影响 Backend profile 版本/编辑 API、资料迁移与媒体绑定，小程序个人/设置/资料页面、真实共享衣物/历史展示与生成契约。复用已有认证、媒体及账户锁，不新增手机号、时区、注销或社交数据。

覆盖 AC-010/020/022/023/027 的个人设置职责。与统计共享装配、路由及生成契约的写入串行整合；最终宿主权限、视觉与产品体验保持待验。
