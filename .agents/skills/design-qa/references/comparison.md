# 还原比较规则

先核对 snapshot、目标/平台、状态、主题、逻辑尺寸、导出倍率和内容区域。状态栏/安全区/浏览器 chrome 不一致时明确裁剪区域和锚点，不从错误图像顶边判断所有间距。未知尺寸/无法对齐：记录 evidence_gap；精确视觉验收不得 passed。

有效期望来自同一项目规则、设计状态与已批准适配；规则发现与冲突处理见 [共同协议](../../DESIGN-WORKFLOW.md)。核对组件 public/API/变体和 Token 角色/主题/控件契约，不把 Lint、同色或截图相似当成语义符合。声明范围只限实际读取/检查的对象。

对齐系统/宿主与内容区域后仍检查整页集成、应用标题/返回/导航承担者；不能通过裁剪隐藏重复顶栏或缺失业务内容。

完整页面任务覆盖所有主要区块及重要状态，局部任务覆盖受影响区域和必要宿主集成；测量对关键组件/Token 抽查，不因抽查八个值正确就宣称整页通过。每项记录 element、expected（原设计或已批准适配）、actual、evidence、severity、suggested_fix。

测量定位原因，截图检查最终呈现。子控件值正确仍可能有父布局/裁剪/字体回退问题；不能修改正确值去掩盖其他问题，也不能以正确值忽略明显错位。未测量不是豁免：补测或列证据不足。

Web 数值比较：长度默认 ±1 CSS px，圆角/边框 ±0.5px，字号 ±0.5px，颜色标准化后精确；每项可明确收紧/调整。原生采用目标逻辑单位和实际测量能力，不能把 CSS 容差伪装成设备测量。

文案/列表条目数/动态图像可按任务授权豁免具体内容，但容器、换行、溢出和缺失结构不豁免；业务需要准确文案时不能忽略。字体抗锯齿噪声可以豁免，导致实际截断/布局错误的字体回退不能自动通过。规范适配须显示原值与有效期望，不宣称原图 pixel-perfect。

blocker：区块缺失、无法使用或结构错误。major：明显布局、资产、样式或状态偏差。minor：不影响任务的细微偏差。没有 blocker/major 且覆盖足够、无关键证据缺口才可给出视觉 passed。脚本返回的是采集/数值检查结果，不是自动视觉结论。

每轮保存源码/构建标识、snapshot、平台/状态、采集条件、差异、适配/豁免、修复及剩余。不记录凭据。运行行为是否通过只依据实际已执行的断言/操作结果，不依据相似截图。
