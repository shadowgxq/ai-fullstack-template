# 项目视觉初始化

仅在用户显式调用 `$project-init` 时执行。不从普通业务、局部样式修改或用途查询自动推断初始化授权；调用本入口不等于授权清空设计目录。

1. 读取 [根约束](../../../AGENTS.md) 和 [前端入口](../../../frontend/AGENTS.md)，确认目标工作区、当前改动与用户本次授权。
2. 读取并执行 [复制模板后的视觉初始化](../../../docs/engineering/frontend/guides/project-bootstrap.md#复制模板后的视觉初始化)，按其中的模式选择规则确定 `cleanup` 或 `rebuild`；未指定时先询问，选择前只做只读盘点。这是模式、初始化范围、替换顺序、清理边界与验证的唯一正文；不要执行同页的上游同步章节，除非另有明确要求。
3. 按该正文、[资产登记](../../../docs/design/README.md#资产登记) 和实际影响定位设计资产、组件与正式 Token 源，区分公共组件和示例画板，不按 Pen 文件数量或名称推定清理范围；需要制稿或还原时加载实际可用的全局 Skill，不复制其规则或用普通文件编辑器改 Pen 结构。执行请求应完成获授权操作，不只返回计划；仅分析请求保持只读。
4. 按 [方案与引用清理](../../../docs/engineering/frontend/guides/project-bootstrap.md#方案与引用清理) 处理已确认被替代的方案与直接引用，按 [验证范围](../../../docs/engineering/common/README.md#验证范围) 选择检查；清理结论不能只依据旧路径搜索结果。
5. 在当前回复或已有 PR/change 记录实际变更、检查、未完成项与恢复位置，然后返回原协调者。不另建初始化状态文件，不自动启动业务交付、合并或发布。
