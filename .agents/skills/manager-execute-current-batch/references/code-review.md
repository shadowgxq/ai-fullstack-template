# 独立代码审查

默认派一个实际可用的原生通用 subagent 承担只读 Reviewer 职责；用户明确 review=off 时省略。当前会话协调实现、并行任务结果与进度，不建立固定角色文件或模型/权限配置。
交接当前需求、实际 diff、项目规范和已有代码检查结果。逐 Change 审查已完成的改动，使已验证的上游能释放下游依赖；阶段收尾只补集成及新增 diff，可复用同一 Reviewer 与有效结论。Reviewer 只查逻辑/权限/契约、token/组件与源码可判断的 UI 问题，不启动浏览器，不重复运行没有疑点的检查。
输出具体问题、文件位置、影响、修复建议；无法从代码证明的视觉/交互疑问列为人工待验，不误报代码失败。仅风格偏好不阻塞。
实现者按问题修复和复验，Reviewer 只复查修复及受影响部分。没有实际独立线程时说明独立审查未完成，不伪造身份；可继续无依赖的代码工作，但不能宣称独立审查已通过。审查职责与执行职责分离，不把某个实现者对自己改动的自查登记为独立审查。
