# Vue Web

确认目标包的 Vue 版本、SFC/JSX 用法、Options/Composition API 风格、路由、状态及组件库。按现有 `.vue` SFC 和项目约定实现，不先生成 React hooks 再机械转译，不强制升级 Vue 或新增样式库。

核对 props、emits、slots、v-model 及响应式状态，沿用 scoped/global 样式边界、语义 Token 和真实数据接口。复用不能以牺牲页面布局、状态和可访问性为代价。

验证使用项目实际 vue-tsc/测试/构建命令（存在才用）；运行与视觉复用 Web 采集，不为 Vue 再复制验收器。

官方：https://vuejs.org/guide/scaling-up/sfc.html
